# 地方志引文核对

地方志编校员用：把 OCR 页稿换成的校样与**引文目录**比对，找出校样里可能漏标的
引文。Flask 网页 + SQLite 存储历版页稿、引文目录与每版引文核对结果。

## 运行

```bash
docker compose up --build        # 打开 http://localhost:8000
```

本地开发（Python 3.11+）：

```bash
pip install -r requirements.txt
DATABASE_PATH=./data/app.db python -m app.main
pip install -r requirements-dev.txt
python -m pytest tests/          # 自测
```

## 使用

### 1. 导入引文目录

在「引文目录」页上传 UTF-8 CSV（每行 `书目号,引文文字`，首行可为表头）：

- 每份最多 **10 万行**、**32 MiB**；
- 匹配时两边都忽略空白和 Unicode 标点；目录里的每条引文去掉这些字符后须为
  **4～40 字**，否则整份拒收；
- 处理后相同的引文若对应**多个书目号**，整份拒收（同书目号重复连登只留一条）；
- 导入在单个事务里完成：失败（包括中途出错）时继续使用原有目录，不会留下半份
  目录；
- 成功导入生成新的**目录版号**，旧版保留。网页顶部与核查结果都显示当前目录版号。

### 2. 上传校样

在首页上传一页纯文本（UTF-8，≤1200 字）与可选的引用位置 CSV
（`引用号,起始下标,结束下标`，下标从 0 起算、右端不含）。

### 3. 从已发布版详情页核查

打开某一版详情页（`/pages/<版号>`）即用当前生效目录核查该版：

- 忽略空白与 Unicode 标点后，列出目录引文在该版页稿中的**全部命中**；
- 重叠的命中都保留（同一引文的多处重叠出现、不同引文互相重叠都逐条列出）；
- 每项给出**书目号、目录原文、原稿命中文字、原稿区间**：区间从 0 起算，
  左端是首个匹配字符，右端紧接末个匹配字符且不含；
- 若本版某条**已定位引文完整覆盖**该命中区间（`引文起 ≤ 命中起` 且
  `命中止 ≤ 引文止`），跳过该命中并显示跳过数量；
- 核查一页只用**一份完整目录**：默认最新生效版，也可在核查页钉住旧目录版号；
  核查过程中即使目录被替换，本次结果仍来自开始时确定的那一版；
- 单页核查先按目录的四字索引取候选，只碰与页面相关的少量条目，**不扫描整份
  目录**（10 万行目录下 1200 字页稿约 0.1 秒）。

### 4. 引文位置随新版校样迁移（原有功能）

上传新校样时，每条已登记引用以它最近一次成功定位的页稿为源稿，与新校样做整页
比对（同一对稿件只比对一次）：增、删、替换各记一次改动；**所有**最少改动的对齐
都把引文逐字对到同一段连续位置时登记新位置，否则标为「待核对」。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 最新版详情页（含上传表单、各版导航） |
| GET | `/pages/<版号>` | 指定版详情页，含引文目录核查结果 |
| GET | `/pages/<版号>/check` | 单独核查页，可用 `?catalog_version=` 钉住目录版 |
| POST | `/pages` | 表单上传页稿（`text` 文件、`citations` CSV 可省） |
| GET/POST | `/catalog` | 引文目录页 / 导入并替换目录（字段名 `catalog`） |
| GET | `/api/versions` | 版号列表 |
| GET | `/api/pages/latest` | 最新版 JSON |
| GET | `/api/pages/<版号>` | 指定版 JSON |
| POST | `/api/pages` | JSON 发布：`{"text": "...", "citations_csv": "..."}` |
| GET | `/api/catalog` | 当前目录版本与版本列表 |
| POST | `/api/catalog` | JSON 导入目录：`{"catalog_csv": "..."}` |
| GET | `/api/pages/<版号>/check` | 核查 JSON，可用 `?catalog_version=` 钉住目录版 |

核查 JSON：

```json
{
  "version": 3,
  "catalog_version": 2,
  "catalog_entry_count": 51234,
  "located_count": 8,
  "skipped": 2,
  "hits": [
    {"book_no": "B017", "citation": "子曰：“学而时习之”",
     "start": 120, "end": 128, "excerpt": "子曰：学而时习之"}
  ]
}
```

没有引文目录时核查返回 409。发布页稿的 JSON 中每条引用含
`status`（`located`/`pending`）、`start`/`end`、`located_version`、`excerpt`。

## 判定方法

- 规范化：`app/normalize.py` 去掉 `ch.isspace()` 与 Unicode 类别 `P*` 的字符，
  同时保留「规范化下标 → 原稿下标」映射，命中区间由此还原。
- 候选检索：每条目录引文只索引首、中、末三个四字组合；页稿命中该引文时这三个
  组合必然都出现，故可先用索引取候选，再逐条精确匹配（`app/catalog_check.py`）。
- 重叠命中：逐起点扫描，不跳过已命中位置，因此重叠项全部保留。
- 位置迁移：`app/align.py` 计算前后缀两张 Levenshtein DP 表，判断一条引文的
  每个字符在**所有**最优对齐中是否都唯一匹配且落点连续。

## 未完成项 / 说明

- 下标按 Unicode 码点计（与 Python 字符串一致）；未做全半角、繁简、组合字符
  等规范化，录入前需先统一文本。
- 中文引文较短（4～40 字），四字索引为保守预筛，候选仍会逐条精确验证；
  若目录大量引文共用相同四字组合，单页候选会增多，但不会扫描整份目录。
- 无登录/权限控制，仅限内网资料员使用；生产部署请自行加认证并设置
  `SECRET_KEY` 环境变量。
- 整页引文位置迁移为 O(字数²) 纯 Python 实现，1200 字上限内约 1 秒。
- 并发写依赖 SQLite 单写者 + WAL + busy_timeout；目录替换期间其他窗口读取旧
  目录不受阻塞。多资料员同时导入时后到者可能需重试。
